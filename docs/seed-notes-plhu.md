**Revision 2** - this replaces the first pass. Reason for the revision: the app only shows rows whose `end_at` is in the future, and a review found 16 of the original 36 rows had an `end_at` before today (2026-09-06), even though several were mislabeled `confirmed` rather than `past`. Every one of those 16 rows was re-checked individually: rolled forward to a real next-edition date where I found genuine multi-year recurrence evidence (4 rows), or dropped where I could not (12 rows). ## Part 1: Rollover review of the 16 past-dated rows

### Rolled forward (kept, `date_confidence=estimated`) - 4 rows

1. **Hacknarok -> Hacknarok 2027** (Kraków). Evidence: original row described it as the "10th edition" (EESTEC AGH Kraków, in Park Lubicz). An explicit archive/edition-2 page could not be opened (hacknarok.pl returned only a bare title, crossweb.pl blocks WebFetch with 403), but the 10th-edition claim is itself edition-number evidence of a long-running annual series. Slot used: same weekday one year later (2026-04-18 Sat -> 2027-04-17 Sat, 2026-04-19 Sun -> 2027-04-18 Sun), i.e. +364 days, not a naive +365. This preserves the Sat-Sun hackathon slot but the exact April weekend for 2027 is **not independently confirmed** - flagging this as the weakest of the four rollovers.
2. **Hack4Change -> Hack4Change 2027** (Gdańsk). Evidence: strongest of the four. Directly fetched three different editions: 4th edition ran 21-23 June 2024 (kosmonauta.net), 6th edition ran 26-28 June 2026 (hack4change.tech, original row), and I found a live aggregator page for the 7th edition, whatdahack.pl/events/hack4change-2027, explicitly dated **25-27 June 2027**, same organiser (Fundacja CODE:ME), same city. This is a directly-sourced future date, not a pattern guess - about as solid as a rollover gets. Kept the source_url pointing at that 2027 page.
3. **EnsembleAI Hackathon -> EnsembleAI Hackathon 2027** (Warszawa, Politechnika Warszawska). Evidence: the original page explicitly called the 2026 run the "3rd edition" (elka.pw.edu.pl), and 494 applications / 205 selected shows a serious, well-established annual event with partners mBank/JetBrains/Cyfronet. Could not find a dedicated 2025 or 2027 page (EnsembleAI-Hackathon-2025 URL 404'd). Slot used: same weekday one year later (2026-03-14 Sat -> 2027-03-13 Sat, 2026-03-15 Sun -> 2027-03-14 Sun). Flagging that the exact 2027 date is a pattern estimate, not independently confirmed.
4. **Kieleckie Dni Informatyki (Nocne Programowanie) -> ...2027** (Kielce). Evidence: kielce.eu and tu.kielce.pl both state the initiative has run "since 2018," and re-fetching tu.kielce.pl/kieleckie-dni-informatyki-2026-enter-the-ai-future/ gave an exact 2026 date (14-15 April 2026) that I had previously only approximated. tu.kielce.pl/kdi-2027 does not exist yet (too early to be published). Slot used: same weekday one year later (2026-04-14 Tue -> 2027-04-13 Tue, 2026-04-15 Wed -> 2027-04-14 Wed). Flagging the 2027 date as a pattern estimate.

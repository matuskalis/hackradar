# Research Notes: Online Hackathon Platforms Seed Data

Date of research: 2026-09-06. Tool constraint: WebSearch was unavailable/exhausted for this
session; all research was done via WebFetch starting from the URLs supplied in the task and
following links/API endpoints discovered on those pages. `devpost.com` was never fetched.

## Per-row verification notes

1. **Lablab x AMD AI Academy Challenge** — verified on its own lablab.ai page (`/ai-hackathons/amd-lablab-ai-academy-challenge`). Individual-only participation, $5,000 pool, Sep 1–Dec 1 2026. Confirmed.
2. **AssemblyAI - Voice Agent Hackathon** — own lablab.ai page. Month-long, rolling join, $10,000 pool, 2,110 registrants at fetch time. Confirmed.
3. **AI Infra Summit Hackathon** — own lablab.ai page. Hybrid; on-site portion is invite-only at Santa Clara Convention Center; online build days Sep 10–16, on-site Sep 15–17 (I used the outer Sep10–17 window). No prize amount stated on page. Confirmed.
4. **WeAreDevelopers Hackathon** — own lablab.ai page. Hybrid, co-located with WeAreDevelopers World Congress North America (San Jose). No prize figure given on page. Confirmed.
5. **IBM Bob 2.0 Hackathon** — own lablab.ai page. Fully online, 48h, $10,000 pool, 8,565 registrants. Confirmed.
6. **AMD Developer Hackathon: ACT III** — own lablab.ai page. Hybrid; on-site hubs explicitly listed as Rome, Milan, Imperia (Italy) — could not attribute to one single city so `city` left blank, `country_code=IT`. Confirmed.
7. **TechEx Amsterdam Hackathon** — own lablab.ai page. Hybrid, venue RAI Amsterdam. Two lablab fetches disagreed slightly on the end date (Oct 19 vs Oct 20); I used the wider Oct 16–20 window (covers the full online+on-site event) and note the discrepancy here.
8. **ETHOnline 2026** — dates/format (async, online, Sep 4–16 2026) taken from the `ethglobal.com/events` listing page, which loaded successfully. The individual event page `ethglobal.com/events/ethonline2026` returned HTTP 500 on three separate attempts, so prizes/eligibility/organizer detail beyond the listing could not be verified — left blank rather than invented. Confirmed (date), but page-level detail unverified.
9–11. **MLH Global Hack Week: Data Week / Hacktoberfest / Builders Week** — all three taken from `ghw.mlh.com` (the GHW hub, reached after `ghw.mlh.io` 302-redirected there), which explicitly lists these three as the next upcoming editions with dates, describes the program as "100% free... for anyone, anywhere," and gives the registration link `mlh.link/ghw`. This is the MLH Global Hack Week series the task explicitly said runs monthly — these are the real next three editions as stated by MLH itself (not extrapolated), so marked `confirmed` rather than `estimated`. Note: a separate MLH page (`mlh.com/seasons/2026/events`) additionally listed earlier 2026 GHW editions (May "GenAI", June "Hacking for Good") which have already passed — those were excluded. One individual past-edition detail page (`events.mlh.com/events/14302-...`) was fetched to sanity-check the format and literally said "this event has ended," confirming GHW editions are single self-contained weeks, not one continuous listing error.
12. **AnimalHack 2026** — own page `animalhack.org`. Confirmed online, Sep 13 2026, single day. Registration is via a Devpost link (`animalhack2026.devpost.com`) — I did not scrape Devpost itself, only recorded the URL as shown on the non-Devpost source page, consistent with the "don't use devpost.com" rule (that rule is about not scraping Devpost as a listing source).
13. **Banana Hacks 2026** — own page `bananahacks.tech`. Confirmed, Oct 9–12 2026, fully online (Discord/Zoom), 150 registrants at fetch time, $10,000+ prize pool.
14. **Build for Earth** — page `earth.firstcommit.xyz` rendered almost no content on WebFetch (only the title came through); dates (Nov 8 2026 – Jan 16 2027) and "online" status are taken from the `hackathons.hackclub.com` index page instead, which is the page actually opened and read. Flagged as lower-detail-confidence in this note; date itself still `confirmed` since it was explicitly listed with concrete dates on the Hack Club index.
15. **Building with IBM Bob Hackathon (AngelHack)** — own page `angelhack.com/event/building-with-ibm-bob/`. Explicitly "Virtual (online only)," Sep 28–Oct 18 2026. Page also showed a generic "Location: United States" tag on the homepage listing card; this may indicate a US-oriented timezone/deadline (submission deadline stated in ET) rather than a hard geographic restriction — flagged as uncertain, included as `open`/online since the page text says "virtual" and "open to all skill levels" with no explicit country restriction in the body copy.
16–28. **Unstop hackathons (13 rows)** — Unstop's own site pages (`unstop.com/hackathons/...`) would not render past the header/title for WebFetch (likely JS-hydrated content), so these could not be opened as normal HTML pages. Instead, I found and used Unstop's public JSON API endpoint `https://unstop.com/api/public/opportunity/search-result?opportunity=hackathons&oppstatus=open` (paginated with `&page=2..6`), which returned real, structured event data (name, slug/URL, start_date, end_date, location) directly from Unstop's backend for currently-open hackathons. I only kept entries whose `location` field was `"online"`/`"Online"` and whose end date is after 2026-09-06, and whose name plausibly indicates a build/submit hackathon (excluded entries titled "Technical Online Assessment" / "Code Club Round 2 - Technical Online Assessment" since those read as screening tests/quizzes, not build-and-submit hackathons; also excluded "Hackcache'26" — its API end_date, 2026-10-20, was earlier than its start_date, 2026-10-23, an apparent data inconsistency — and "Dogfood 72-Hour Hackathon" / "Qiskit Fall Fest," which had no usable date field). Because I could not open the human-readable pages, prizes/eligibility detail beyond name/organizer/theme is inferred conservatively (student-run college hackathons marked `eligibility=students`; company-run ones marked `open`) and should be treated as **best-effort, not independently verified** — flagged here for a later pass with a tool that can render Unstop's JS. Dates themselves are `confirmed` (came straight from the platform's own API), but eligibility/theme inference is soft.
    - Several of these entries had precise ISO timestamps with `+05:30` offsets in the API (e.g. Agentic GraphRAG Hackathon, BuildForge Hackathon, Hacknexus, Unfoldd CTF 2026, QuHack Hackathon, Aven Coding Hackathon 2.0) — those exact timestamps/offsets were kept as given and `timezone` set to `Asia/Kolkata`; entries that only had a bare date (no time) were given the task's default 09:00–18:00 UTC window per the field rules.

## Uncertainties worth a follow-up pass

- Unstop rows' eligibility (`students` vs `open`) is inferred from organizer name only (college vs company), not from reading actual eligibility text, since individual Unstop pages wouldn't render for this tool.
- ETHOnline 2026 and Build for Earth detail fields (prizes, exact organizer copy) are thinner than the rest because their own pages could not be fetched (500 error / empty render respectively); only listing-page data was usable.
- AngelHack "Building with IBM Bob Hackathon" shows "Location: United States" on the listing card despite being described in its own page body as "Virtual (online only)" — likely just indicates the deadline timezone (ET) rather than a geo-restriction, but not 100% certain.
- capacity values recorded for lablab.ai rows are the "current registrants" counter shown on the page at fetch time, not a hard capacity limit (lablab hackathons appear to have no fixed capacity cap).
